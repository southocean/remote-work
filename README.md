# Vietnam remote stint

A planning site for a few months of remote work and writing in Vietnam. It covers the timeline, choosing a city, a budget, housing in Vietnam, subletting the bostadsrätt in Sweden, work, admin, daily life and the writing routine.

Live: https://southocean.github.io/remote-work/

Each section is its own tab (#stay, #sublet, …). It's a static site (`index.html`, `style.css`, `app.js`) with no build step. Checklist ticks, the budget and the scratchpad are saved in the browser's localStorage, so they're per device.
